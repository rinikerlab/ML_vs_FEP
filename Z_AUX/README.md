# Auxiliary Analysis

## Overview

Exploratory notebooks for supplementary analyses and visualizations not part of the main pipeline.

## Contents

### `ANALYZE_DG_DISTRIBUTION.ipynb`
Analysis of experimental dG (binding free energy) value distributions across protein targets and compounds.
- Informs stratification strategy for model training

### `LOOK_AT_PDE_10_COMPOUNDS.ipynb`
Detailed examination of the PDE10 protein target dataset due to its unique performance.
- Produces PDE10_MOLECULES.png


### `PDE10_MOLECULES.png`
Rendered molecule images for PDE10 compounds.
