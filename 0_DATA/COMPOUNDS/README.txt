COMPOUNDS DATA - README
=======================

Column Descriptions
-------------------

All columns are values extracted from https://github.com/dfhahn/protein-ligand-benchmark-analysis.git

DG_conv
  Calculated binding free energy (ΔG) in kcal/mol (conv for converted)
  Calculated from Ki, pKi or IC50 values using: ΔG = RT ln(K), where IC50 is interchangable with K (see paper)
  Temperature: T = 300 K
  Rounded to 2 decimal places 

DG_Exp.
  Directly extracted from https://github.com/dfhahn/protein-ligand-benchmark-analysis.git
  Are essentially the same values as DG_conv. but not rounded
